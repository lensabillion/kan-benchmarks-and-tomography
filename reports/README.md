# Reports — the box file

One report per line of research. Each report stands on its own: what the notebooks set out
to test, how they tested it, what the numbers came out as, and what can honestly be claimed
from them.

**Filing convention.** Reports are numbered and filed in order. A new report goes at the
back — take the highest number, add one, and append a row to the bottom of the index below.
Reports already filed are not renumbered; if a finding is superseded, the newer report says
so and the older one stays in place as the record of what was believed at the time.
